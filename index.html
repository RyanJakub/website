    E. About the Data

    This project represents airports as vertices and unique domestic airport connections as edges. Airport coordinates are used to plot the map. The network summary calculates airport degrees and connected components. The connection checker uses breadth-first search (BFS) to determine whether a path exists between two airports.

    Data source: OpenFlights airport and route datasets. The website uses the prepared JSON files in the data folder.

    Results reflect the airports and routes included in the supplied dataset; they may not represent current airline schedules.
